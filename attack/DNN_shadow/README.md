# シャドウモデルを使ったメンバーシップ推定攻撃
### 学習フェーズ
Ai.csvを使ったシャドウモデル・攻撃モデル訓練用データセットを作成（今回は、Ai.csvを2万レコードの5つのデータセットに分割し、5つのシャドウモデルを作成）。このデータセットを用いて、入力レコードがmember-Inかmember-Outかを予測する2クラス分類モデルを作成。

入力：訓練データ（1レコードが真のクラス、シャドウモデルでの予測確率、In/Outラベル（訓練データに含まれているか）からなる10万行のデータ）

### 攻撃フェーズ
入力：検証データ（Ai.csvの真のクラスとターゲットモデルでの予測確率からなる1万行のデータ）

出力：1/0（メンバー/非メンバー）からなる10万行のデータ。1の数は1万に制限。

## ファイルの説明
- split_to_2K.py input.csv [--prefix output.csv]
    - 10万レコードのデータを2万レコードの5つのファイルに分割
- concat.py output.csv [input files]
    - 複数のcsvファイルを結合
- xgbt_pred_edit.py model.json --test-csv input.csv --output-csv output.csv
    - xgbt_pred.pyを出力層で0/1ラベルに変換する前の確率値[0,1]を出力するものに改造
- attack_train_and_predict.py train.csv valid.csv Fij.csv
    - 訓練データtrain.csvを受け取って攻撃モデルを学習。学習した攻撃モデルを用いて、ターゲットモデル（攻撃対象のXGBoost）から作成した検証データvalid.csvに対するメンバーシップ推定攻撃を行う。
    - 出力は0/1（訓練データに含まれていたか）の1列10万行のデータ
    - 訓練データと検証データは同じ（分布の）データセットから作る必要がある

### 生成物
- teami（ディレクトリ）
    - Fi.csv
        - チームiに対するメンバーシップ推定攻撃の結果（10万行のデータ）
    - train.csv
         - Ai.csvから作成した攻撃用訓練データ
    - valid.csv 
        - Di.jsonの予測から作成した攻撃対象のデータ
        
## 攻撃精度
- いずれのチームの加工データに対しても約10%

## 改善の方針
- 攻撃モデルの入力データの次元が小さく、情報量として不十分
- GXBoostから得られる他の指標（寄与度など）を入力データに追加して、次元を増やす
- モデルからの情報のみを用いた攻撃手法なので、加工データの情報も使った手法を検討すべき
