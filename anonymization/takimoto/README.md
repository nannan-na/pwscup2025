# 匿名化の方針
1. 医療統計で利用する特徴量に対して、年齢で群分け、同列内で郡内スワッピング（選択した特徴量：num_procedures、num_immunizations、num_medications、num_devices、encounter_count）

2. p値、関係係数、オッズ比、95%信頼区間より、athma_flagへの影響が小さい特徴量へのノイズ付加、別カテゴリへの置換、2値反転を実施

3. レコードをランダムシャッフル



## 利用ファイル
- swapping.py [input.csv] [output.csv] [0.2(=scale)]
    - 医療分析に使われる5特徴量に対して列内で郡内スワッピング
    - スワッピングするペアは、各郡ごとにシャッフルして、隣同士をペアにして入れ替える（ランダムペアリング）
        - レコードの近さから入れ替えるペアを選ぶと、より分布が変わらないかも（同じ年齢や近い年齢、同じ性別、レコード間の距離を測る指標を導入するなど）
    - scaleはスワッピングするデータの割合
    - encounter_count、num_medication、num_proceduresはVIFやPearsonの相関行列からみて相関が強く、個別にスワッピングするとstatus.pyのスコアが下がったため、同一ペアでスワッピングに変更

- ano.py [input.csv] [output.csv] [--seed 2]
    - mean_bmi：athma_flagへの影響が弱いため、強めのノイズを付与
    - mean_diastolic_bp、mean_systolic_bp：athma_flagへの影響はそこそこ弱いため、値域を考慮してノイズを付与
    - num_procedures：athma_flagへの影響はそこそこ弱いが、クラスカル検定への影響を考慮して、弱めのノイズを付与
    - num_immunizations、num_medications、num_devices、encounter_count：athma_flagへの影響が小さくないのと、クラスカル検定への影響を考慮して弱めのノイズを付与
    - depression_flag：athma_flagへの影響は小さいため、15%の割合で2値反転を実施
    - RACE、ETHNICITY：10%の確率で他クラスの値に置換（athma_flagへの影響は小さいが、クラス不均衡のため、少数クラスへの過剰な加工は、分析結果を大きく変える可能性あり。）

- randomshuffle_rows.py
    - レコードをランダムで入れ替える
